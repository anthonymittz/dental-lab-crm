# Glossary

- **CRM**:  
  Centralized resource management.

- **GUI**:  
  Graphical user interface.

## Programming

- **Interface**:  
  A contract, a blueprint that defines *what* actions a component 
  must perform, without dictating *how* it performs them.

- **Coupling**:  
  A measure of how much one piece of code depends on another.  
  Tight/high: components are deeply connected and intertwined.
  Loose/low: components are mostly independent, 
  interacting via stable boundaries/interfaces.

- **Scope**:
  Visibility and accessibility of a variable, function, or object 
  within different parts of a program's source code.

- **Pure function**:
  Pure is a function without side-effects, 
  it *always* returns the same output for identical inputs.

- **Side-effect**:  
  interaction with something outside the function's immediate scope;
  can take indefinite time, time-out, etc; the response time may vary, 
  the output may differ for identical inputs.
